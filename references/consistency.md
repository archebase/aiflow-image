# Consistency

For repeated subjects or style families, create a consistency dossier before iteration:

- subject identity and invariant physical features;
- approved reference images and rights;
- camera, lens, lighting and palette anchors;
- environment and material anchors;
- prohibited changes;
- accepted master candidate and file hash.

Use the same references and preserve invariant prompt clauses across variants. Do not claim consistency from filenames or subjective memory; compare contact sheets and image metadata. If the available API does not support the required reference-image operation, report the limitation rather than pretending prompt-only consistency is guaranteed.
