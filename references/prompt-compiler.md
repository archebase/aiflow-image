# Prompt compiler

Compile prompts in this order:

1. Deliverable and placement.
2. Subject and action.
3. Composition, camera and negative space.
4. Material, lighting and environment.
5. Visual style and finish.
6. Immutable constraints.
7. Explicit exclusions.

Keep final typography, Logo and precise diagrams out of the generation prompt. Ask for clean space where deterministic overlays will be placed. Record the complete prompt, model, size, quality, output format, reference files and backend.

For iterations, change one named variable set at a time: composition, subject pose, environment, palette or detail density. Preserve all other accepted constraints.
